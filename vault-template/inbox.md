# Inbox

Things to file, one per line. Action items are `- [ ] Owner — what`; the
owner is optional, and a line without one is mine. Notes are plain bullets:
an answer to an open question, a link between items, or a decision or detail,
as `- [[topic-slug]] — what` when the topic is known. The next ingest run
files each line and removes it from here. A line it can't file stays, with a
note saying why.
